In this video we continue with the static and dynamic analysis of the CCM SEPIC converter by deriving its small-signal model. The video shows how the small-signal model is obtained by linearizing the analytical averaged model developed in previous video PE #125. The implementation of the small-signal model in Qspice is also shown. Several simulation results are shown to illustrate the use of the small-signal model.
